# AGENTS.md

## What This Repo Is

LaTeX CV/resume for Xiangyu Wang (王翔宇). Two versions:

- **English**: `cv-llt.tex` → `cv-llt.pdf`
- **Chinese**: `cv-llt-zh.tex` → `cv-llt-zh.pdf`

Uses the `curve` document class (not standard article/report). Style lives in `settings.sty`.

## Architecture

```
cv-llt.tex          ← English main document
cv-llt-zh.tex       ← Chinese main document (requires XeLaTeX)
settings.sty        ← Shared style, fonts, layout, colors
own-bib.bib         ← Bibliography (IEEE style via biblatex)
photo.jpg           ← Profile photo
web/index.html      ← Update-check landing page

# Content sections (English → Chinese pairs):
education.tex       → education-zh.tex
awards.tex          → awards-zh.tex
research.tex        → research-zh.tex
projects.tex        → projects-zh.tex
coursework.tex      → coursework-zh.tex
skills.tex          → skills-zh.tex
languages.tex       → languages-zh.tex
referee.tex         (references — no Chinese version)
```

Each section is a standalone `.tex` file using `\begin{rubric}{Title}` / `\entry*[date]{content}` syntax, included via `\makerubric{section-name}` in the main document.

## Build Commands

**English PDF** (pdfLaTeX):
```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error cv-llt.tex
```

**Chinese PDF** (XeLaTeX — mandatory for `ctex`):
```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error cv-llt-zh.tex
```

Clean build artifacts:
```sh
latexmk -C
```

## CI/CD (GitHub Actions)

`publish-resume.yml` triggers on:
- Push to `main` → build check (no publish)
- Tag `v*` or `release-*` → build + create GitHub release with PDFs

Version is a 12-char SHA256 hash of content files. CI writes `build-version.tex` (gitignored) which `\docversion` reads at compile time.

**Local builds**: `\docversion` defaults to `local` when `build-version.tex` doesn't exist.

## Key Quirks

1. **XeLaTeX required for Chinese**: `cv-llt-zh.tex` loads `ctex`; will fail with pdfLaTeX.
2. **`build-version.tex` is ephemeral**: Auto-generated by CI, gitignored. Don't commit it.
3. **`\fullonly` comment gate**: Controls photo and "check for update" button. Toggle with `\includecomment{fullonly}` / `\excludecomment{fullonly}`.
4. **biblatex loaded but unused**: Settings include biblatex setup and `own-bib.bib`, but the main docs don't call `\printbibliography`. The bibliography infrastructure is inherited from the upstream template.
5. **`referee.tex` has no Chinese counterpart**: Only English version exists.
6. **Photo path**: Just `photo` (no extension) — LaTeX resolves `photo.jpg` automatically.
7. **Upstream template**: Based on LianTze Lim's `curve` CV template. Comments in `settings.sty` and `cv-llt.tex` reference the original author.

## Editing Content

- Edit the English `.tex` file for content changes, then mirror to the `-zh.tex` counterpart
- Section order is set by `\makerubric{}` calls in the main document (currently: education → awards → research → projects → coursework → skills → languages)
- Each `\entry*[date]` creates a dated entry; `\entry*[]` creates an undated entry
- Links use `\href{url}{text}`; icons via fontawesome5 (`\faGithub`, `\faEnvelope`, etc.)

## What NOT To Do

- Don't commit `*.pdf`, `build-version.tex`, or LaTeX intermediates (`.aux`, `.log`, `.bcf`, etc.)
- Don't edit `settings.sty` unless changing global styling — it's shared between both versions
- Don't use pdfLaTeX for `-zh.tex` files
- Don't add new sections without updating both English and Chinese main documents
